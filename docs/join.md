# Join a game in under 2 minutes (issue #24)

Two players, one link, laughing in under two minutes. The host sends the
build URL; the guest is at the first goal before the kettle boils.

1. The host copies the build link (the `wss://` page URL from
   `docs/web-fallback.md`) and sends it to the guest — the guest can
   open link in any desktop or mobile browser, no install needed.
2. Both players open the menu and type name into the name field, then
   confirm — hats and coins follow the name on this device.
3. The host creates a room and reads out the 4-letter lobby code; the
   guest picks Join and type code into the code field, then presses Join.
4. The host picks World 1 Stage 1 and presses Start; both players run to
   the glowing goal — the stage clears only when everybody is inside.

Trouble? Reload the page and rejoin with the same name and code; goals,
coins, and wardrobe live on the server, not the tab.
